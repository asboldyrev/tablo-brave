# Табло для Brave

Локальное расширение Chromium Manifest V3, заменяющее новую вкладку. Сайты и папки хранятся **в обычных закладках Brave**, оформление — в `chrome.storage.local`.

## Установка

1. Распакуйте архив в постоянную папку.
2. Откройте `brave://extensions/` и включите режим разработчика.
3. Выберите «Загрузить распакованное расширение» и укажите папку с `manifest.json`.
4. Для обновления замените файлы **в той же папке**, затем нажмите «Обновить» в Brave.

Рекомендуется предварительно экспортировать закладки.

## Возможности v0.5.0

- Три размера плиток, сетка с всплывающими папками, поддержка вложенности.
- В заголовке папки — кнопка «Назад» и два ближайших уровня пути; `…` обозначает более глубокую вложенность.
- Добавление, редактирование, удаление и перенос закладок. Для перемещения в родительскую сетку можно вынести плитку за пределы всплывающей папки.
- Размеры, отображение названия/иконки, фоновое изображение Bing.
- Часы и поисковая строка в верхней части, плитки по центру окна.
- Цвет карточки с сайта (тег `theme-color`) либо генерация по цветам иконки. Источник задаётся для отдельной карточки и по умолчанию в настройках.
- В настройках — обновление **только** иконок и цветов существующих сайтов; названия, URL, порядок и папки не меняются.
- Авторство фона является ссылкой: на страницу Bing, если она указана API, либо на исходное изображение.

## Разрешения и приватность

Расширение обращается к Bing для фонового изображения. Запросы к сайтам выполняются по кнопке «Получить данные сайта» либо при пакетном обновлении, с разрешением браузера для соответствующего домена. Без этого разрешения сайт не опрашивается. Данные не отправляются на сервер разработчика.

В случае проблем с загрузкой иконки или цвета можно задать цвет вручную. Некоторые сайты не позволяют получить метаданные из-за авторизации, CSP или отсутствия публичных метаданных.

## Известные ограничения

- Прямого доступа к HTTP-кэшу Brave расширения не имеют.
- Сложные сценарии drag-and-drop необходимо проверять в самом Brave. Автотест Chromium покрывает начало/завершение и операцию drop, но не все сочетания вложенных папок.

## 0.5.2 — миниатюры вложенных папок

В превью внешней папки показываются только её четыре непосредственных элемента.
Если элемент — ещё одна папка, его миниатюра представляет собой четыре
цветовых прямоугольника по первым четырём дочерним элементам без иконок
и названий. Для вложенных папок цвет берётся с первой доступной ссылки
внутри них; пустые ячейки остаются серыми.

## Погода (v0.6)

В настройках включите «Погода», введите название населённого пункта, нажмите значок поиска и выберите город из вариантов. Показаны температура в °C и иконка текущих погодных условий. Данные [Open-Meteo](https://open-meteo.com/) обновляются не чаще одного раза в час и сохраняются в `chrome.storage.local` (последний результат остаётся при ошибке сети). Геолокация не запрашивается. Поиск города обращается к `geocoding-api.open-meteo.com`; погода — к `api.open-meteo.com`.

- Единый внутренний отступ 18 px для стеклянных блоков плиток и часов/поиска.
- Ширина верхнего блока динамически равна фактической ширине сетки (ResizeObserver), включая разные размеры плиток и адаптивные колонки.
