# Табло для Brave — 0.2.0

Небольшое локальное расширение для Brave (Chromium, Manifest V3). Заменяет страницу новой вкладки крупными плитками и папками, которые открываются **поверх текущего Табло** и закрываются кликом снаружи или `Esc`.

## Установка в Brave на Linux

1. Распакуйте `tablo-brave.zip` в постоянную папку, например `~/extensions/tablo-brave`. Не удаляйте папку после установки.
2. Откройте `brave://extensions/`.
3. Включите **Режим разработчика** (Developer mode).
4. Нажмите **Загрузить распакованное расширение** (Load unpacked) и укажите **папку с файлом `manifest.json`**.
5. Если Brave спросит, разрешить ли расширению изменять страницу новой вкладки, подтвердите.
6. Откройте новую вкладку (`Ctrl+T`).

Если уже установлено другое расширение, меняющее новую вкладку, отключите у него соответствующую функцию или само расширение.

## Как пользоваться

- **Добавить сайт** и **Создать папку** над плитками создают элементы на главной.
- Для добавления **внутрь папки** сначала откройте её, затем используйте кнопки `+ Сайт` / `+ Папка`.
- **Кнопка с тремя точками** на плитке (или контекстное меню по правому клику): открыть, изменить, переместить, удалить.
- Изменить название/URL/папку можно через **Изменить**.
- **Перетащите плитку** на другую для изменения порядка. Перетащите её в центр папки, чтобы вложить в неё; у левого и правого края папки можно менять порядок.
- Если папка открыта, можно перетащить плитку **на хлебные крошки** (например, «Табло»), чтобы переместить её выше по дереву.
- Клик **по пустому месту вне всплывающей папки** или `Esc` закрывает её.
- Шестерёнка в правом нижнем углу открывает настройки: часы, поиск, размер плиток, вид карточек, фон Bing и затемнение.
- В форме карточки кнопка «Получить название и цвет сайта» запрашивает разрешение на этот сайт и читает `<title>`, `og:site_name` и `theme-color`. Это действие не обязательно; цвет можно указать вручную.

## Где лежат данные

В обычном дереве закладок Brave автоматически создаётся папка **«Табло Brave»**, как правило внутри **Другие закладки**. Это источник всех плиток и подпапок. Изменения в менеджере закладок отражаются в Табло, а изменения в Табло — в закладках.

**Важно:** удаление элементов в Табло удаляет соответствующие закладки. Удаление папки удаляет также все вложенные элементы — перед этим запрашивается подтверждение. Перед экспериментами рекомендуется экспортировать закладки Brave (`brave://bookmarks/` → меню → Экспорт закладок).

Иконки сайтов запрашиваются через штатный механизм favicon браузера. Для фона дня расширение обращается к Bing. Список закладок Bing не передаётся. Для загрузки заголовка и цвета со страницы требуется отдельное разрешение на указанный сайт. Сайты могут не публиковать `theme-color`, а некоторые запрещают такие запросы. Для работы нужны права `bookmarks`, `storage`, `favicon`, доступ к Bing и необязательный доступ к сайтам по запросу.

## Обновление

Замените файлы в папке расширения и нажмите кнопку обновления у расширения на странице `brave://extensions/`. Закладки сохраняются отдельно от файлов расширения. **Не удаляйте папку «Табло Brave» в закладках**.

## Особенности версии 0.2

- Папки открываются в диалоге поверх страницы, а не как отдельная страница.
- Поддерживаются вложенные папки, редактирование, удаление с подтверждением и перетаскивание.
- Нет прямого импорта данных из собственного «Табло» Яндекс Браузера, автодобавления часто посещаемых сайтов и собственного выбора картинок плиток.
- Brave/Chromium не позволяют обычному расширению открывать Табло при клике на адресную строку.
- В режиме приватного окна Chromium не поддерживает замену новой вкладки расширением.

## Совместимость с 0.1

Папка «Табло Brave» не пересоздаётся, данные остаются в закладках. Настройки и цвета карточек хранятся в `chrome.storage.local` и привязываются к идентификаторам закладок. Сначала сделайте экспорт закладок и скопируйте текущую папку расширения, затем замените файлы и нажмите «Обновить» в `brave://extensions/`. Не удаляйте расширение: при удалении Chrome/Brave может стереть его локальные настройки.


## 0.4.0

- Поиск через текущую поисковую систему Chromium (`chrome.search`).
- Кнопка «+» после последней плитки, ПКМ для выбора папки или сайта.
- Обновление размеров миниатюр папок, отключён drag у вложенных изображений, выход перетаскивания на главную.
- Предпросмотр иконки в редакторе; локальные данные вкладок и Табло сначала по точному URL, затем по домену (HTTP cache Chromium не читается).
- Цвет из нескольких meta theme-color с учётом media, предпочтение содержательным цветам.
- Bing: подпись на полупрозрачной подложке, ссылка на источник при наличии.
